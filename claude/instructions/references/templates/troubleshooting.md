# 트러블슈팅 기록 템플릿

문제 해결 기록(회고, 이슈 정리, devlog의 해결 항목)에 적용한다.
전체 과정은 PR·커밋·티켓에 이미 있으므로 재문서화하지 않는다.

## 골격

```markdown
# {증상을 담은 제목}

- 증상: {무엇이 어떻게 실패했는가. 1줄}
- 원인: {근본 원인. 1줄}
- 수정: {적용한 해결책. 1줄}
- 교훈: {재사용 가능한 일반화. 1줄. 없으면 행 제거}
- 참조: {PR/커밋/티켓 링크}
```

## 금지

- 호출 체인 추적, 로그 덤프, 기각된 대안 비교, 단계별 검증 로그.
- 상세 서술은 미해결·후속 작업 항목에만 허용된다.
- 문서의 TL;DR이 이미 해결 내용을 요약하면 별도의 상세 "해결된 이슈" 섹션을 만들지 않는다.
