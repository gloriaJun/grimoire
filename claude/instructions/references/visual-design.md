# Visual Design Choices

Applies when the user asks for a palette, theme, typography, or the overall look of a screen.

- Never finalize a visual choice from hex codes, font names, or prose alone.
- Present 2-3 rendered samples the user can actually see: self-contained HTML files
  plus the command or path to open them.
- Let the user pick. This is the explicit exception to the one-recommendation rule
  for ambiguity in "HOW TO WORK FOR ME".
- Keep the samples visually distinct enough to be a real choice. Three near-identical
  palettes are one option, not three.
